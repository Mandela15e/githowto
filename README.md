# GitHowto - Git õppimise projekt

## Projekti kirjeldus 
Selles projektis läbisin GitHowTo õpetuse ja õppisin Gití kasutamist
ning versioonihaldust.

## Mida õppisin?
 Git repository kasutamine
 Muudatuste salvestamine
 Commitíde tegemine
 Branchíde kasutamine
 Branchíde ühendamine

## Põhilised Git käsud
 git status - kontrollib projekti
 git add - lisab muudatused staging areaśse
 git commit - salvestab muudatused 
 git log - näitab commitíde ajalugu
 git branch - näitab commitíde ajalugu 
 git branch - haldab branche 
 git switch - vahetab branche
 git merge - ühendab branche 
 git push - saadab muudatused GitHubi
 ## Gití põhitöövoog

git status 
git add README.md
git commit -m "Täienda README dokumentatsiooni"
git push 
Kõigepealt kontrollitakse muudatusi,seejärel lisatakse need staging areaśse,tehakse commit ja lõpuks saadetakse muudatused GitHubi
